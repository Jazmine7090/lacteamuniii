

# Lactea MUN Conference Website

A modern, immersive static website for the Lactea MUN conference at Alyammah University, Riyadh (April 17–18, 2026).

## Design Direction
- **Color Palette**: Deep navy/cosmic blues, soft whites, gold accents, with a galaxy/space-inspired theme tying into the "Lactea" (Milky Way) name
- **Typography**: Clean, modern fonts — bold headings with elegant body text
- **Animations**: Smooth scroll reveals, parallax hero, hover effects on cards and buttons, animated countdown timer
- **Style**: Sleek, professional, youth-oriented with a cosmic/diplomatic aesthetic

## Sections to Build

### 1. Navigation Header
- Fixed/sticky transparent header that becomes solid on scroll
- Logo + nav links: About, Event Details, Team, Opportunities, Committees, Apply Now (CTA button with gold accent)
- Mobile hamburger menu

### 2. Hero Landing Section
- Full-screen hero with animated starfield/galaxy background
- Lactea MUN logo and tagline centered
- Countdown timer to April 17, 2026
- Prominent "Apply Now" CTA button with glow effect
- Smooth scroll-down indicator

### 3. About Section
- Inspiring description of the event's mission
- Key highlights: leadership, public speaking, global awareness
- Subtle fade-in animations on scroll

### 4. Event Details Section
- Date & venue info with icons
- Two-day schedule overview in a clean timeline/card layout
- Day 1: Opening ceremony, committee sessions
- Day 2: Final sessions, closing ceremony & awards

### 5. Committees & Topics Section
- Placeholder committee cards (e.g., UNSC, UNHRC, DISEC)
- Each card with committee name, topic, and brief description
- Hover animations on cards

### 6. Meet the Team Section
- 6 secretariat member cards with circular photo placeholders
- Name, position, and subtle hover reveal
- Roles: Secretary-General, Deputy Sec-Gen, Head of Press, etc.

### 7. Opportunities Section
- Benefits cards: public speaking, networking, leadership, certificates
- Placeholder testimonial quotes from past participants
- Engaging icons/illustrations

### 8. Application CTA Section
- Bold call-to-action banner
- "Apply Now" button linking to placeholder external form

### 9. Footer
- Instagram link, contact email
- Copyright line
- Quick nav links

## Technical Approach
- Single-page React app with smooth scroll navigation
- Intersection Observer for scroll-triggered animations
- CSS animations for starfield hero background
- Fully responsive with mobile-first approach
- Countdown timer component calculating days/hours/minutes/seconds to April 17, 2026
